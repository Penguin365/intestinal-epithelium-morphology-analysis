# Intestinal Epithelium Morphology Analysis

This repository contains the core morphology analysis code developed for my
PhD thesis. The analysis pipeline was used to quantify simulated 3D
intestinal epithelial structures generated by the agent-based model.

## Core functionality

The current `Analysis_demo` pipeline includes:

- loading and organising simulation output data
- screening simulation results for analysis quality
- creating/loading User Manual Count (UMC) table
- calculating cell number and cell-type composition
- measuring mean and maximum epithelial height
- quantifying surface variation from mean local curvature
- PCA and BPA screening for pass-rate style filtering
- villus counting by two methods:
    - XY alpha-shape method
    - XZ heightmap regional-maxima method
- curvature metrics from point-cloud normals
- optional BPA/topology merge from Python-generated CSV
- summary output (`.csv` and `.mat`)

## Repository contents

## Requirements

The demo uses MATLAB and Python.

Expected tools include:

- MATLAB (with Statistics and Machine Learning Toolbox for `knnsearch` and
    `rangesearch`; Image Processing Toolbox for `medfilt2`, `imregionalmax`)
- Python 3 with `numpy`, `pandas`, and `pymeshlab` (optional BPA step)
- simulation output files from the 3D epithelial model

## How to run

Run MATLAB summary pipeline:

```matlab
cd('path to/Analysis_demo')
run_analysis_demo
```

Run optional BPA/topology helper separately:

```bash
cd path to/Analysis_demo
python3 python/batch_BPA_topo_measure_demo.py \
        --input example_data/NCI_6_SR_1.25_TP_0.7_GlobalIR_1.5 \
        --output demo_output/bpa_topology_measurements.csv
```

`run_analysis_demo.m` does not call Python automatically. MATLAB only reads
`demo_output/bpa_topology_measurements.csv` if it exists.

## Algorithm sources and references

### Third-party code included directly

- `external/findPointNormals.m`
    - Original source: MATLAB File Exchange
        https://uk.mathworks.com/matlabcentral/fileexchange/48111-find-3d-normals-and-curvature
    - Author notes and header comments are kept in the copied file.

### BPA topology step (Python)

- PyMeshLab documentation:
    - https://pymeshlab.readthedocs.io/
- Ball Pivoting Algorithm paper:
    - Bernardini et al., 1999, "The Ball-Pivoting Algorithm for Surface
        Reconstruction"
    - https://doi.org/10.1109/2945.817351

### PCA-based thickness metric

- The demo uses a local PCA thickness peak-ratio as a screening criterion.
- In this pipeline, PCA is used with BPA to decide whether a complete
    simulation result should enter the next analysis stage.
