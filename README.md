# Intestinal Epithelium Morphology Analysis

This repository contains the core morphology analysis code developed for my PhD thesis. The analysis pipeline was used to quantify simulated 3D intestinal epithelial structures generated by the agent-based model.

## Thesis context

This code supports the quantitative analysis of simulated epithelial morphologies in my PhD thesis. It was used to process simulation outputs, screen valid results, extract morphology metrics, and compare simulated structures with reported intestinal organoid-on-a-chip observations.

## Core functionality

The public version of this repository will include algorithms for:

- loading and organising simulation output data
- screening simulation results for analysis quality
- calculating cell number and cell-type composition
- measuring mean and maximum epithelial height
- quantifying surface height variation
- detecting villus-like structures
- counting villus-like peaks
- summarising morphology metrics across parameter sets
- generating compact demo outputs for validation
